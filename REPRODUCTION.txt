Mechanism Memory: reproduction instructions (updated 21 November 2026)
=================================================================

Repository contents: code, protocols, parameter locks and saved experiment
records. DATA_GUIDE.md gives the data-directory map and a short reproduction
workflow. Clone with `git clone --depth 1` or use GitHub's Download ZIP, then
run commands from the repository root.

Run commands from the project root with Python 3.12. H below means
data/historical/; R means data/controlled/results/.
P means analysis/historical/; E means data/controlled/experiments/.
This map distinguishes saved-byte validation, saved-result replotting and new
protocol runs. It does not establish preregistration or an earlier tuning history.

1. Versions and lightweight commands
------------------------------------

data/controlled/experiments/reproduction_snapshot.json pins 21 historical archive members and
75 inspected source/result files by SHA-256. These are inspected bytes, not an
inferred original-run commit. The two archived neural drivers equal their
causal_sandbox copies byte for byte. Other historical drivers are not in that
old data archive; the snapshot pins the current inspected implementation.
The historical baseline snapshot is
c1655d69b5a8316b67d5f09cac0a4df9f97c8fe6.

python -m pip install -r requirements.txt
python reproduce.py map
python reproduce.py validate
python reproduce.py figures --output ../reproduced_figures
python -B analysis/tools/test_historical_reproduction.py

The replot output must be a NEW directory outside the checkout. It produces
six data figures in PDF/PNG, table_inputs/ and replot_record.json. It reads saved
intervals without bootstrapping and fits no model. --scope historical selects
the three historical data figures; --scope added selects the three added ones.
Validation needs only the standard library; replot additionally needs numpy and
matplotlib. Neither command loads neural weights, imports torch/transformers,
acquires interventions or trains a decoder. Rendering/font/PDF metadata can
differ from the original PDFs. Validation checks saved hashes and the archived
verify_reported_results.py assertions, not an independent experimental rerun.

The driver reads the saved records in H directly from the repository.
An optional --source-zip PATH
accepts the original data archive; its required SHA-256 is
1630d251114f5de421ff60aa5365ff3eecb050d4387d9fac4b6ebf65bf0ea248.
Both input modes check member hashes. Historical plotting scripts run from
temporary copies. Run commands from the repository root. manifest.json records
the measured dependency versions, not a recovered historical software/BLAS/CUDA
environment.
