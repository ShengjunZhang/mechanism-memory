Source data for the JMLR submission

This directory contains the numerical values and raw result files underlying
the empirical results in the manuscript.

Figure and table data
- SourceData_Fig2_fixed_probe_outcomes.csv
- SourceData_Fig2_cross_domain_mechanism_gap.csv
- SourceData_Fig3_tdmpc2_distributional_retention.csv
- SourceData_Fig4_llm_hidden_retention.csv
- SourceData_Table4_tdmpc2_by_task.csv
- SourceData_Table5_llm_proposal_policies.csv

Raw results
- raw_json/finite_agent_comparison_complex_100x5.json
- raw_json/matched_mechanism_baselines_8families_2seeds.json
- raw_json/ranking_and_adaptation_baselines_8families_2seeds.json
- raw_json/continuous_metric_comparison_20seeds.json
- raw_json/continuous_noise_sweep_20seeds.json
- raw_json/tdmpc2_distributional_retention_3tasks_3seeds.json
- raw_json/llm_proposal_policy_comparison_3seeds.json
- raw_json/llm_hidden_retention_12train_6test.json
- raw_json/candidate_budget_sensitivity_4families.json

Reproduction files
- make_probe_figures.py rebuilds Figure 2 from its CSV tables.
- make_llm_hidden_figure.py rebuilds Figure 4 from its CSV table.
- tdmpc2_retention.py runs the distributional intervention-response protocol.
- llm_hidden_retention.py mirrors the frozen-Qwen experiment driver in the
  full repository; run that repository copy as module
  causal_sandbox.llm_hidden_retention.
- verify_reported_results.py checks the reported numerical claims against the
  packaged JSON files.

The TD-MPC2 experiment uses the official MT30 5M checkpoint from
https://github.com/nicklashansen/tdmpc2. The checkpoint is not redistributed.
Its SHA-256 digest is
f3c6909e3282f115ce57b2ab29a88e654b4728d819d2c93a4ca079bad63b1455.

The hidden-state experiment uses Qwen2.5-7B-Instruct snapshot
a09a35458c702b33eeacc393d103063234e8bc28. Model weights and cached hidden
vectors are not redistributed; the raw probe results and complete extraction
script are included.

Figure 1 is a schematic and has no numerical source data. All reported values
are generated by deterministic scripts using the seeds and protocols stated in
the manuscript.

Run the numerical check from this directory with:

    python verify_reported_results.py
